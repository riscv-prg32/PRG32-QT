# Code of Conduct

PRG32-QT is an open-source educational and technical project. Participation should be respectful, constructive, and focused on the work.

Expected behavior includes welcoming technical disagreement, giving actionable review feedback, respecting different levels of experience, and avoiding harassment, discrimination, personal attacks, or publication of private information.

Project maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when necessary to protect the community.

For conduct concerns that should not be handled publicly, contact the repository owner through their public GitHub profile and request a private channel.
