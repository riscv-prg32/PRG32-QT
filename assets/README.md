# PRG32 application artwork

The artwork in this directory is derived from the canonical PRG32 logo/application icon contained in the attached MIT-licensed PRG32-iOS baseline. `prg32_appicon_1024.png` is the source application icon used to generate desktop/mobile variants.

Run `python3 scripts/make-icons.py` after replacing the source artwork. Platform packages should use the generated PRG32 icon and must not introduce third-party console branding or trade dress.
